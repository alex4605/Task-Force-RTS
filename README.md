# Task Force RTS · 特遣艦隊 1942–1991

俯視角的海陸空聯合作戰即時戰略遊戲。你指揮一支美軍特遣艦隊與它的航空隊、陸戰隊及陸軍部隊，從 1942 年的所羅門群島一路打到 1980 年代的北海與北德平原。地圖、島嶼與敵軍部署每局程序生成；艦艇、飛機、地面部隊與設施都以向量線稿依實物平面圖繪製。

以 React 19 + TypeScript + Vite 開發，全部畫面用 Canvas 2D 即時繪製，不依賴任何遊戲引擎或圖片素材。

## 五個時代

| 時代 | 年代與戰場 | 我軍 | 盟軍 | 敵軍 |
|---|---|---|---|---|
| 時代一 | 1942 瓜達爾卡納爾、所羅門群島 | 美國海軍第 16 / 61 特遣艦隊、陸戰隊 | 紐西蘭、澳洲、荷蘭、英國 | 日本海軍與陸軍 |
| 時代二 | 1944–45 雷伊泰、沖繩、塞班、硫磺島 | 第 38 / 58 快速航艦特遣艦隊、B-29 | 英國太平洋艦隊、大英國協 | 日本 (神風特攻、萬歲衝鋒) |
| 時代三 | 1950–53 韓戰東海岸 (元山—咸興) | 第 77 特遣艦隊、陸戰隊第 1 師、美陸軍 | 大英國協、南韓、土耳其、希臘、法國 | 朝鮮人民軍、中國人民志願軍、蘇聯 |
| 時代四 | 1965–73 越戰 (北部灣、第一軍區) | 小鷹號航艦群、陸戰隊、空騎 | 澳洲、南韓、南越、泰國 | 北越軍、越共、蘇聯 |
| 時代五 | 1983–91 假想第三次世界大戰 (北海、北德平原) | 尼米茲號航艦群、神盾艦 | 北約各國 (英、西德、荷、法、加) 與日本 | 蘇聯與華沙公約 |

時代一、二在環礁與島嶼群作戰；時代三到五是大陸戰線：南方四分之一是我軍與盟軍的防區，其餘為敵控區。

單位與設施依三個原則挑選：**年代正確**（該年確實已服役）、**合理的數量**（當時常見的裝備，而非孤例）、**能投送到該戰場**。

## 主要玩法

- **艦隊作戰**：航艦、戰艦、巡洋艦、驅逐艦、護航艦、魚雷艇、潛艦與兩棲艦艇，各有依史實的武裝、航速與吃水（淺水區會擱淺）。主砲可設定交戰規則。
- **航空作戰**：每座機場與航艦有各自的機庫與掛載；可出擊、轉場、護航、劃定 CAP 空域；打擊包含護航編組；預警機與雷達決定空情圖。B-29 / B-52 飛在高射砲射高之上。
- **兩棲與地面作戰**：LCVP / LST / LCAC 搶灘，攻佔各島與大陸的據點。地面部隊依其武器作戰（戰車砲、迫擊砲曲射、火焰噴射、反戰車飛彈或火箭、機砲、機槍），地形、城鎮與散兵坑提供掩蔽。
- **反潛作戰**：主動 / 被動聲納、溫躍層、聲納浮標、吊放聲納、深水炸彈、刺蝟砲與反潛火箭、反潛魚雷，潛艦會規避與反擊。
- **電子戰**（時代四、五）：ECM 干擾、ESM 截收、EMCON 靜默、箔條 / 熱焰彈 / 魚雷誘餌，以及各型飛彈尋標器的抗干擾特性。
- **戰爭經濟**：MP 人力、RP 資源、PP 政治、TP 時間四種資源。增援、構工與艦艇維修都要消耗；攻佔據點會推進戰役階段，提高動員程度與產出。
- **定居點與平民**：村鎮有建築完整度 (BLD) 與人口 (POP)，戰火會造成破壞與難民潮，誤擊會扣政治值；我方勢力範圍內的城鎮、工廠、車站可產出資源並募集地方部隊。
- **搜救與戰俘**：飛行員跳傘、艦員落海，可派艦艇搜救海域或派直升機吊掛救援（救回可得 TP）。落在陸地的機組員會躲藏並避開敵軍；雙方據點都會派巡邏隊搜捕敵方飛行員，俘虜可送進戰俘營。
- **機場損傷**：機場分五級損傷，影響哪些機型能起降與出擊數量，由工兵與地勤慢慢修復。
- **作戰圖鑑**：所有艦艇、飛機、地面部隊與設施的介紹、數據與攻擊方式，圖片即遊戲內的實際繪圖。

## 操作

| 操作 | 功能 |
|---|---|
| 左鍵 / 拖曳框選 | 選取單位 |
| 右鍵 | 移動、攻擊、登船 / 搶灘、救援落水人員 |
| 滑鼠中鍵或 Alt + 左鍵拖曳、WASD / 方向鍵、滾輪 | 平移與縮放視角 |
| Space / Backspace | 暫停 |
| `[` `]` | 調整遊戲速度 |
| Ctrl + 1–4、1–4 | 設定 / 選取編隊（連按兩下跳轉視角） |
| Q / E / A | 增援選單 / 設施構工 / 機場面板 |
| C | 劃定 CAP 空域 |
| G | 投放聲納浮標 |
| T / V | 飛機轉場 / 護航指定飛機 |
| P / B / X | 巡邏 / 返航 / 停止 |
| F | 鏡頭跟隨選取單位或旗艦 |
| R | 雷達涵蓋圖層 |
| M / Tab | 戰術地圖 |
| D / Y / K / Z / U | 吊放聲納 / EMCON / 潛艦誘餌 / 挖散兵坑 / 空投卸載 |
| F3 | 設施放置模式 |

## 開發

需要 Node.js 22。

```bash
npm install
```

```bash
npm run dev
```

開發伺服器在 http://localhost:3000 。

```bash
npm run lint
```

（TypeScript 型別檢查）

```bash
npm run build
```

輸出到 `dist/`，使用相對路徑，可直接部署到靜態主機。

### 部署到 GitHub Pages

`.github/workflows/deploy-pages.yml` 會在每次推送到 `main` 時自動建置並發佈。第一次使用需在儲存庫的 Settings → Pages → Build and deployment 將 Source 設為「GitHub Actions」。

## 專案結構

```
src/
  App.tsx, main.tsx          React 進入點與遊戲迴圈
  components/                HUD、各種選單與彈出視窗、Canvas 元件
  game/
    engine.ts                遊戲狀態與每幀模擬
    procedural.ts            地圖、島嶼、據點與兵力生成
    terrain/                 地形網格、導航與交戰地形判定
    render/                  艦艇、飛機、地面部隊、設施、投射物等繪圖
    allied/                  盟軍行動
    naval/                   吃水、海運等海軍系統
    economy.ts               四資源經濟
    groundWeapons.ts         地面部隊攻擊方式
    asw.ts, ew.ts            反潛與電子戰
    codex.ts, unitIntro.ts   作戰圖鑑資料
  types/game.ts              共用型別
```
